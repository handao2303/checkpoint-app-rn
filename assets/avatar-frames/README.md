# Checkpoint Avatar Frames SVG Pack

This pack contains:

- Badge-based avatar frames
- Level-based avatar frames from level 1 to level 50

## Level formula

level n starts at:

100 * (n - 1)^2 XP

Examples:
- 0 XP -> level 1
- 100 XP -> level 2
- 400 XP -> level 3
- 900 XP -> level 4
- 1600 XP -> level 5
- 2500 XP -> level 6
