# Checkpoint Badge SVG Icon Set

Bộ SVG icon được vẽ lại theo style mobile profile: warm orange, glassy hex badge, soft shadow, travel achievement theme.

## Files
- `badge-first-step.svg` — Bước chân đầu tiên / Flag
- `badge-explorer.svg` — Nhà thám hiểm / Compass
- `badge-country.svg` — Vòng quanh đất nước / Map + Pin
- `badge-night-owl.svg` — Cú đêm / Moon
- `badge-traveler.svg` — Kẻ lữ hành / Suitcase
- `level-50.svg` — Cấp độ 50 / Level medal

## Usage
Có thể dùng trực tiếp trong React/Next.js bằng `<img src="/icons/badge-first-step.svg" />` hoặc import như asset nếu bundler hỗ trợ SVG.
